# Sources and attribution

Researched and checked 12 September 2026.

The instructional text and cube diagrams in Rubik’s Cube Practice are original. Cube diagrams are generated from actual sticker permutations, not copied from reference sites. Algorithms are recommended starting choices; ergonomics, finger tricks, grip and orientation affect their speed.

## Algorithm data

119 case records (41 F2L, 57 OLL, 21 PLL), including alternative sequences, are adapted from Luke Jackson's cube project:

- https://github.com/lukejacksonn/cube
- https://github.com/lukejacksonn/cube/blob/master/src/algorithms.ts

The project README declares the data/software MIT licensed. Parentheses were flattened and equivalent half-turn notation normalized. OLL 32 and OLL 52 alternative transcription errors were corrected against J Perm's sequences. All primary OLL and PLL sequences were compared with J Perm's public algorithm trainer. F2L case numbering follows the source dataset; other references may number F2L cases differently.
